# पवित्र बाइबल — Nepali Bible (Android)

A simple, ad-free Nepali Bible reader with very large text, made for an elderly reader.

- Full Bible (66 books) built in, works offline
- Big text with अ− / अ+ buttons, light/dark mode
- Opens where you left off
- Choose book → chapter → verse
- Highlight verses in 4 colours, list of all highlights
- Read aloud (uses the phone's Nepali or Hindi text-to-speech voice)

## Getting the APK
Every push builds the app automatically. Open the **Actions** tab, click the latest
"Build APK" run, and download **nepali-bible-apk** at the bottom of the page.

You can also open this folder in Android Studio and use
**Build → Generate App Bundles or APKs → Generate APKs**.

## iPhone and iPad version
The `docs` folder is the same app as a home-screen web app, published with GitHub Pages.
Open the link in **Safari** → **Share** → **Add to Home Screen**. It works offline after the first visit.
